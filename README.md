# Week 2: Exploratory Data Analysis and Visualization

This project performs Exploratory Data Analysis (EDA) on the Diabetes dataset using Python, Pandas, Matplotlib, and Scikit-learn.

The analysis includes data inspection, descriptive statistics, missing-value and duplicate checks, correlation analysis, and six visualizations to identify patterns, relationships, and potential outliers.

## Key Features
- Dataset exploration and statistical summaries
- Correlation heatmap
- Histograms and scatter plots
- Outlier detection using boxplots
- BMI quartile analysis
- Visualizations with titles, labels, and legends
- Detailed report with findings and interpretations

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn

## Project Files
- `eda_analysis.py` – Python analysis script
- `diabetes_eda_dataset.csv` – Dataset
- `requirements.txt` – Dependencies
- `Week2_EDA_Final_Report.docx` – Final report
- `visualizations/` – Generated charts

## How to Run
```bash
pip install -r requirements.txt
python eda_analysis.py
```

## Objective
To extract meaningful insights from a public dataset through data analysis and visualization.

**Dataset Source:** https://scikit-learn.org/stable/datasets/toy_dataset.html#diabetes-dataset
